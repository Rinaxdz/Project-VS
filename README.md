# 🌿 Ninang's On-The-Go Tots

A modern, responsive website for **Ninang's On-The-Go Tots**, a childcare service inspired by Filipino values of warmth, trust, and family care.

🔗 Live Site: https://ninangsonthegotots.vercel.app/

---

## ✨ Features

- Clean, elegant UI design
- Fully responsive (mobile, tablet, desktop)
- Multi-page structure with **clean URLs (no .html)**
- Smooth scrolling and animations
- FAQ accordion with category filtering
- Mobile-friendly navigation drawer
- Deployed using **Vercel**
